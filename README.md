# Menstrual Tracker

A Next.js (App Router) + shadcn-style + Tailwind CSS menstrual cycle tracker.

- Enter 1–3 last period start dates
- Set your own cycle length in days (e.g. 26 or 27) and bleeding length
- Predictions for next period, ovulation, fertile window and PMS window
- Predictions blend the actual gaps between entered dates (65%) with the stated cycle length (35%)
- Data is stored only in the browser (localStorage)

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this project into Vercel, or deploy with the Vercel CLI / API. No environment variables are needed.
